# Harlow's Accidental Journey

> A picture book by Lois Farrell — finished spreads in a click-through lightbox gallery.

**Branch policy:** work happens on the latest *-vN / project branch. List branches before editing. Never assume the GitHub default is the working line. Working line: `main` (GitHub default is `main`).

## Live preview

https://mydigitalstudioz.github.io/Harlows-Accidental-Journey/

## What's inside

- `index.html` — the gallery page (warm storybook design, no frameworks)
- `spreads/` — the six finished spreads (Pages 1–6), full-bleed 2:1
- Click any spread to open the lightbox: arrow-key / swipe-button navigation, spread counter, captions
